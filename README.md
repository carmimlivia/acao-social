# Sistema Ação Social

Sistema web para cadastro e gerenciamento de pessoas atendidas por uma ação social.

## Objetivo

Centralizar os dados das pessoas atendidas, reduzindo cadastros duplicados e facilitando a consulta das informações.

## Problema

Atualmente, os dados das pessoas atendidas são registrados manualmente, o que pode gerar:

- duplicidade de cadastros;
- dificuldade de consulta;
- retrabalho;
- falta de histórico organizado.

## Funcionalidades planejadas

- Autenticação de usuários
- Cadastro de pessoas
- Validação de CPF
- Busca por nome e CPF
- Edição de cadastro
- Agenda de ações sociais
- Dashboard administrativo
